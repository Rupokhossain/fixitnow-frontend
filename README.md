# 🔧 FixItNow – Home Service Marketplace

A modern full-stack home service marketplace where customers can easily book trusted technicians, technicians can manage service requests, and administrators can oversee the entire platform.

Built with **Next.js 15**, **Node.js**, **Express.js**, **Prisma ORM**, **PostgreSQL**, **Redux Toolkit**, and **Stripe Payment Gateway**.

# ⚙️ Installation

## Clone repositories

```bash
git clone [https://github.com/yourusername/fixitnow-frontend.git](https://github.com/Rupokhossain/fixitnow-frontend)

git clone [https://github.com/yourusername/fixitnow-backend.git](https://github.com/Rupokhossain/fixitnow-backend)
```

---

## Frontend

```bash
cd fixitnow-frontend

npm install

npm run dev
```

---

## Backend

```bash
cd fixitnow-backend

npm install

npm run dev
```
